# GDDL @ NeurIPS 2026 workshop paper

Target: Geometric Distributional Deep Learning workshop, NeurIPS 2026.
Deadline: August 29, 2026 AoE. Anonymized four-page short paper,
references excluded from the page limit.

Build:

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Current draft: 4 main pages (body ends on page 4; references occupy
page 5). Line numbers come from the NeurIPS submission mode.

Pre-submission checklist (from docs/WORKSHOP_TARGETS.md):

1. Replace `neurips_2025.sty` with the official NeurIPS 2026 style once
   published (the 2026 styles were not yet downloadable on 2026-07-24);
   re-verify the page count after the swap.
2. Recheck the workshop CFP one week before submission: assigned day,
   template version, supplementary policy, anonymization details,
   archival status, dual-submission policy.
3. Verify anonymization: no author names, repository URLs, or
   identifying artifact paths.
4. Figures are generated by `scripts/make_workshop_figures.py` from
   pinned, checksummed artifacts; sidecars sit next to each PDF.
