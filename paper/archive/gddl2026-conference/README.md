# Historical short draft (not the public preprint)

This directory stores the short conference-style draft that existed at
commit `e48c9390e62b38f206342e6aeb7f160122ccc79c`. It is an archival copy
of TeX sources, style files, and figures. It is **not** the public
preprint.

The public manuscript is `paper/arxiv/`.

Do not treat files here as current claims, author identity, or
distribution text. The draft used an anonymous author block and a
conference style file. Those choices were for a historical short version.
They are not the public face of this repository.

The compiled PDF that used to sit next to these sources was removed from
the tip of this branch. Git history still contains it.

Leftover `neurips_2025.sty` is retained only as part of the archive. Do
not use it for new writing.
