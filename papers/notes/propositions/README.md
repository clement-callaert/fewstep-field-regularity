# Proposition notes

One Markdown file per proposed proposition.

## Required sections

1. Statement
2. Assumptions
3. Symbol definitions
4. Nearest source result
5. Cited steps versus original steps
6. Line-by-line derivation
7. Dimension check
8. Endpoint behavior
9. Singular cases
10. Numerical checks
11. Counterexample search
12. Proof status

## Allowed proof statuses

- sketch
- partially verified
- numerically checked
- source verified
- needs expert review

Never use `proved` unless the user explicitly approves after manual review.
